# Jewellery image set

All active Jewellery photography is grouped in this directory. The campaign, category, navigation, and product images were generated for their exact storefront placements and converted to WebP.

| Placement       | Files                  | Art direction                                                                                           |
| --------------- | ---------------------- | ------------------------------------------------------------------------------------------------------- |
| Collection hero | `collection-hero.webp` | Wide campaign portrait in a sunlit stone gallery with wine silk, antique gold, and garnet.              |
| Mega menu       | `mega-menu.webp`       | Square close portrait with geometric drop earrings and safe headroom.                                   |
| Category shelf  | `subcategory-*.webp`   | Six distinct 4:5 photographs for Earrings, Necklaces, Bracelets & Bangles, Rings, Anklets, and Lockets. |
| Product rail    | `product-*.webp`       | Seven 3:4 still-life photographs on pale limestone with restrained charcoal and oxblood props.          |

## Generation prompt set

- **Collection hero:** One South Asian woman in wine silk wearing an antique-gold collar in a contemporary arched stone gallery.
- **Mega menu:** A close three-quarter portrait with modern geometric gold and garnet drop earrings.
- **Categories:** Model portraits for earrings and necklaces, detail photographs for bracelets, rings, and anklets, and an ivory-silk still life for lockets.
- **Products:** Kiran earrings, Neel enamel collar, Sona cuff, Raat signet, Chandra anklet, Smriti locket, and Rekha bracelet photographed as clean modern catalogue still lifes.

Images were generated with the built-in image generation tool. Prompts required realistic materials and functional jewellery construction, distinct compositions, and no text, logos, or watermarks.
